本地优先 · 零数据收集

LanDeck（la.ksr.landeck）是一款开源的本地桌面端智能控制面板应用。我们高度重视您的隐私：LanDeck 不会收集、上传、出售或共享任何个人身份信息、使用遥测数据、崩溃日志或广告追踪标识。

生效日期：2026 年 11 月 14 日 · 适用版本：LanDeck 桌面端及内置移动端网页（/deck）

1. 我们在本地处理的数据

LanDeck 的所有核心数据均仅保存在您自己的设备本地，不会传输至任何开发者服务器：

  • 布局与配置数据：您创建的控制面板布局、按键动作配置、自定义上传的图标图片以及配对码，仅保存在您电脑的本地应用数据目录（app_data_dir）中。
  • 移动端浏览器本地存储（localStorage）：当您通过手机或平板浏览器访问内置的 /deck 页面时，浏览器仅在本地保存配对码、当前选中的布局 ID 以及浅色/深色主题偏好，以便刷新后保持连接体验。
  • 本地应用扫描与系统监控：为支持「应用启动」和「系统监控」组件，LanDeck 会读取本机已安装应用列表与图标，并实时读取本机 CPU、内存及网络接口速率。这些信息仅用于向同一局域网内已配对的设备实时展示，不会离开您的局域网。

2. 局域网通信与用户主动触发的外部请求

  • 局域网服务：LanDeck 启动后会在您的电脑上运行内置的 HTTP 与 WebSocket 服务（默认端口 19820），仅用于与同一局域网内的移动设备进行面板同步与指令控制。
  • 外部请求（仅由用户主动配置触发）：当您手动配置并使用「打开链接（URL）」、「Webhook」或远程「图片展示（Image）」等动作时，应用会按照您填写的目标地址发起对应请求。LanDeck 不会对这些请求进行中转、记录或分析。

3. 系统权限说明

  • macOS 辅助功能权限（Accessibility）：仅当您使用「快捷键」、「文本输入」或「媒体控制」等模拟键鼠操作时，才需要您在系统设置中授予辅助功能权限。
  • 本地网络权限：用于在局域网内监听连接并提供移动控制端访问。

4. 第三方服务与分析工具

LanDeck 未集成任何第三方统计分析 SDK、广告网络、云端账号系统或远程崩溃上报服务。

5. 未成年人隐私

LanDeck 不主动收集任何用户的个人信息，包括 13 周岁以下（或适用法律规定的其他年龄）未成年人的信息。

6. 隐私政策更新与联系方式

若本隐私政策未来因功能变更而有所更新，我们将直接在本页面及 GitHub 代码仓库中发布最新版本。如果您对本隐私政策或 LanDeck 的数据处理方式有任何疑问，欢迎通过 GitHub Issues 与我们联系。

Local-First · Zero Telemetry

LanDeck (la.ksr.landeck) is an open-source, local-first desktop control panel application. Your privacy matters: LanDeck does not collect, upload, sell, or share any personal data, usage analytics, crash telemetry, or tracking identifiers.

Effective Date: November 14, 2026 · Scope: LanDeck Desktop App & Embedded Mobile Web UI (/deck)

1. Data Processed Locally

All core data in LanDeck stays strictly on your own devices and is never sent to developer-operated servers:

  • Layouts & Configuration: Your panel layouts, button actions, custom uploaded images, and pairing codes are stored exclusively in your computer's local application data directory (app_data_dir).
  • Mobile Browser Storage (localStorage): When you open the embedded /deck page on a mobile browser, localStorage is used solely to remember your pairing code, selected layout ID, and light/dark theme preference.
  • Installed Apps & System Metrics: To power App Launch and System Monitor tiles, LanDeck reads locally installed application metadata/icons and local CPU, memory, and network throughput metrics. This data is streamed only to your paired devices over your local network.

2. Local Network & User-Initiated External Requests

  • LAN Server: LanDeck runs an embedded HTTP and WebSocket server on your machine (default port 19820) solely for syncing layouts and executing actions from mobile devices on the same local area network.
  • External Requests (User-Configured Only): If you explicitly configure actions such as Open URL, Webhook, or remote Image tiles, requests are sent directly to the URLs you specify. LanDeck does not proxy, log, or inspect those requests externally.

3. System Permissions

  • macOS Accessibility: Requested only if you use simulated keyboard/mouse actions such as Hotkeys, Text Input, or Media controls.
  • Local Network: Used to accept connections from paired mobile devices on your LAN.

4. Third-Party Services & Analytics

LanDeck contains no third-party analytics SDKs, advertising frameworks, cloud account systems, or remote telemetry services.

5. Children's Privacy

LanDeck does not knowingly collect personal information from anyone, including children under the age of 13.

6. Policy Updates & Contact

Any updates to this Privacy Policy will be published on this page and in the GitHub repository. If you have questions about this policy or how LanDeck handles data, please reach out via GitHub Issues .
